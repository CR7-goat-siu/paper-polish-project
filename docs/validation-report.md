> 2026-10-25 · 真实稿件：EEG 论文 v7（中文，24 条参考文献）

> 失败如实记录；校验管线对响应一视同仁跑 fail-closed 判定。

## review-sim（模拟同行评审）

- 样本：真实稿构建 32 个作业，填写 17 个（四角色 × 全部章节类型；<100 字的
  章节桩与冗余表格节不重复抽样），产出意见 16 条。
- **锚定通过率 93.8%**：15 条通过；唯一拒检是一次真实的近义词滑笔
  （模型写"训练**和**测试"，原文为"训练**与**测试"）——校验器正确拒绝措辞
  改写，证明 fail-closed 边界既放行排版级差异（弯引号/全角经 anchor 归一），
  又拦截语义级漂移。
- **语义盲区实证**：评审在跨节视图发现表1与表2同一模型同一任务 SNR 数值不一致
  （EOG：23.939 vs 24.349 dB；ECG+EOG：19.068 vs 19.026 dB）——对同一稿件
  跑全量确定性审计（20 个问题）**零命中**该缺陷。语义评审覆盖了确定性规则
  的真实盲区，特性价值主张成立。
- 其余高价值发现：消融变体描述符号脱落、结论判别器主语缺失、摘要"均优于"
  与结果表并列事实矛盾、单种子无方差报告。

## cite-intent（引用证据强度预填）

- 覆盖率演进（同一稿件，27 对 claim-citation）：
  1. 基线（Crossref → OpenAlex DOI → OpenAlex 标题）：**70.4%**；
  2. 修复 GB/T 著录《》标题提取（原 title 字段全空，标题检索链路整体失效）后：81.5%；
  3. 修复标题兜底错配（见下）后的诚实终值：**77.8%**。
- 剩余 6 个无摘要：3 本专著（公开源无摘要，合理）、2 篇早期期刊文章（免密钥源
  无可取摘要）、GAN 原论文（标题检索 top-1 被"Conditional GAN"扩展题占据，
  精确门禁正确拒绝错配后无摘要可用——宁缺毋错）。
- **证据句通过率 100%**：18 条 supporting 判定全部携带可逐字锚定的摘要证据句，
  0 降级、0 拒收；3 条判 background（综述/架构例证不构成直接证据）、6 条判
  mentioning（无摘要）。
- Semantic Scholar intents 交叉信号本轮因共享 IP 限速（429）大部分不可用——
  交叉信号为可选项，不影响门禁，环境限制如实记录。

## 验证过程中发现并修复的管线缺陷（验证的直接副产物）

| 缺陷 | 修复 |
| --- | --- |
| 标题检索兜底对"严格扩展"标题错配（GAN→Conditional GAN，序列相似度 0.95 仍放过） | 标题兜底改为归一化精确相等双门禁（`_title_match_is_exact`） |
| GB/T 著录参考文献 title 字段为空，标题检索链路失效 | 《》/引号标题提取（`_reference_title`） |
| arXiv DOI（10.48550/*）在 Crossref 404 | arXiv Atom 摘要兜底（DOI 直查 + 标题检索） |

## 诚实的局限性声明

- 执行模型与校验器作者同源（本 Agent），逐字复制能力高于一般模型，通过率应视为
  **乐观上界**；跨模型族的通过率未测（需多模型环境）。
- 单稿件（生物医学 EEG、中文）样本；ML/英文稿件的覆盖率与通过率可能不同。
- 门槛（60%/50%）为本报告预先声明的工程标准，非领域规范。

## 跨模型对抗验证（2026-10-25 补充：打破同源三角）

S1 的根本局限是执行模型、校验器作者、失败模式观察者同源。本轮以 dynamic-workflow
引入 **GLM-5.3（非 Flash，异构 checkpoint）** 承担执行与攻击，校验器仅做离线确定性判定。
方法论出处：LLM-as-judge 自偏文献（Wataoka et al., NeurIPS 2024：自偏部分源于"偏好流畅"
且同家族评审系统性高估；跨家族评审是文献推荐的缓解）+ Deterministic Quoting 的逐字
引用失败模式分类 + promptfoo/garak 按已知失败族构造探针的做法。攻击分类学（10 族）
来自上述外部文献归纳，红队代理被明确禁止读取校验器实现（信息不对称）。

### 结果

| 指标 | 数值 | 说明 |
| --- | --- | --- |
| 攻击拦截（must-reject 8 族 × 3 样例） | **24/24 = 100%** | 同义替换/语序重组/翻译/拼接/内部省略/数字漂移/可信杜撰/标点注入全部拦截，**零逃逸** |
| 阳性对照（must-accept 2 族 × 3） | **6/6 = 100%** | 排版归一与逐字复制全部放行——对抗加固没有堵死诚实路径 |
| 跨模型锚定通过率（诚实执行 17 作业） | **96.2%（76/79）** | 与同源 93.8% 相当；3 例拒检全部为执行者真实改写滑笔（和→与、EEG→脑电、引用了原文不存在的错拼），逐例归因为正确拒检 |
| 跨模型 cite-intent 证据句通过率 | **100%（7/7）** | 意图分布 7 supporting + 1 background，与同源判定一致 |

### 跨模型运行的三个附加发现

1. **作业 ID 纪律缺口（产品缺陷）**：GLM-5.3 执行者 17/17 未按指令原样回填 job_id
   （自创 job-1-…/语义名）。生产 fail-closed 会全部拒收（安全成立但不可用）——
   需要宽容 ID 匹配或更强的回填纪律。已记录为待办。
2. **异构评审者真实增量**：GLM-5.3 发现了同源评审遗漏的真缺陷并给出可核算的依据，
   例如混合任务"次优的DiR模型，SNR提升5.12%"的基线错配（5.12% 实为对 SimpleCNN
   的值，对 DiR 应为 5.52%，经计算复核属实）、LSGAN 损失与 Sigmoid 输出+GP 组合的
   技术自相矛盾、λ_rec=10 归因于不存在的消融实验、CBAM/CAS 贡献归因漂移。
3. **红队预言应验**：paraphrase_synonym 族预测的"和→与"滑笔在诚实执行的 3 例拒检
   中真实出现——分类学覆盖了实际失败空间。

### 边界与未覆盖

- GLM-5.3 与 5.3-Flash 同家族（不同 checkpoint），非完全跨家族独立；文献提示即使
  "不同家族"也可能共享数据/蒸馏——完全独立的第三方模型验证仍是待办。
- 攻击语料 30 例、执行 17 作业 / 79 findings，规模为单稿件级别；英文/LaTeX 稿未测。
- 红队的"信息不对称"是指令级的（禁止读校验器代码），非沙箱强制。
- 判定器（tools/eval_anchor_validation.py）与攻击语料、原始结果已入库可复核；
  工作流脚本在 .zcode/workflow-drafts/（宿主管理，不入库）。
