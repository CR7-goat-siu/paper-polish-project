# 模拟坏稿评测集

本目录只包含人工构造、明确标注的模拟坏稿，用于端到端红队与回归测试。
模拟坏稿结果不得作为真实论文质量证据，也不得冒充真实投稿成功率。

## 评分

每篇按 `config/submission.yaml` 的 0–5 分 rubric 评分。硬门禁通过要求：

- 引用证据绑定率 ≥ 95%；
- 统计冲突为 0，或冲突已显式标记并进入作者确认清单；
- 图表完整性 100%，或缺失项已进入作者补件清单；
- DOCX 真实渲染成功且页面非空；
- 无未解决占位符；
- 关键逻辑断层已修复或显式标记；
- 人工签核清单存在且未完成时不得声明最终发表许可。

## 划分

- `dev`：允许用于迭代和规则调试；
- `test`：只用于最终回归，不因单篇失败调整规则措辞；
- 每次修改规则后必须全量重跑，禁止只提交通过子集。
