### 硬约束（违反任意一条即未通过审查）
a. 只允许使用原稿中已经出现的数字、百分比、机构名、数据集名与出处；严禁新增任何原稿没有的事实性内容，即使它"看起来更可信"。
b. 遇到不确定的专业术语、模糊的事实陈述、存疑的缩写或缺乏文献支撑的论断时，严禁凭参数记忆猜测或脑补，必须保持原稿的客观表述，不得"补全"。
c. 原稿中已有的浮夸吹捧词或无依据绝对化表述，必须在本次润色中彻底清除，或降级为有实验数据支撑的陈述。

1. 直接输出润色后的完整文本，不要输出解释、前缀或 Markdown 代码块标记。
2. 如果认为某处改动有风险或无法确定，保留原句，不要猜测。
3. 客观性（仅做词级替换，不得调整句子结构）：
   - 常见替换：空前 -> 明显；革命性/划时代 -> 新颖；国际领先/远超 -> 具有竞争力/优于（需对比数据）；完美 -> 有效；极大/巨大 -> 明显；彻底/完全解决 -> 有效缓解；前所未有 -> 新的；毋庸置疑/毫无疑问 -> 删除；树立标杆/新标杆 -> 删除，或改为“表现良好”；显著（附近无数据时）-> 删除，或补上具体数字；所有难题/所有问题 -> 相关问题（限定范围）。
   - 无法量化的程度副词（完全、彻底、极其、大大）必须直接删除，不得换成另一个强化词。
4. 禁止新增或删除语义内容，禁止修改公式、代码、引用编号、数值与段落数量。
